# Armory Preview Cache

Armory Preview Cache now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Armory Preview Cache's C source is in
[`src/components/armory_preview_cache`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/armory_preview_cache).

The standalone Lua mod (v23.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/ArmoryPreviewCache/tree/legacy) branch. Its releases and tags are unchanged.
