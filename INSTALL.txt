Armory Preview Cache - v23

Speeds up equipment thumbnails in the Armory and mission briefing by caching
rendered previews and preloading their assets.

Release for Steam build 25480438 / EXE 1.8.46015.0. Offline checks passed;
caching works in live play. New in v23, checked offline: a short visit keeps
the thumbnails of the tiles it showed once they have rendered.

INSTALL
1. Close Helldivers 2.
2. Import Armory-Preview-Cache-v23.zip into Arsenal or HD2MM, replacing any
   older entry.
3. Install and enable Bingus Shared Loader v18 or newer alongside it.
4. With Arsenal's default priority, place the shared loader last, then
   Purge / Deploy.

Helmets, armor, capes, primary/secondary weapons and throwables are supported in
Armory grids, both pre-select screens, and mission briefing's overview and
pickers. Completed previews are reused across menu visits. Equipment packages
and weapon attachments load ahead, with current and recently viewed equipment
prioritized.

The learned asset profile survives restarts; rendered images remain
session-only. First-time images still need native rendering. Cache eviction and
memory limits can require an image to be generated again. A retained preview is
bound while the game re-renders the item. After a pattern or attachment change
the tile stops showing the old appearance immediately and presents the new
render as soon as that item is composed. Gameplay and live previews are
unchanged. No quantified cold-start performance claim is made.

OPTIONAL SETTINGS
Create %LOCALAPPDATA%/ArmoryPreviewCache.ini before launch:
  enabled=1
  prewarm=1
  images=1
Set a value to 0 to disable that feature. The retired disk option is ignored.
verify_gate=1 (diagnostic, off by default) also does the full thumbnail read
that unchanged frames skip and logs any difference it finds.
